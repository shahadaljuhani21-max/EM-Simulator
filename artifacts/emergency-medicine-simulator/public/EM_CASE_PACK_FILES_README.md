# Create cases with ChatGPT

1. Extract this ZIP in Files or Downloads.
2. Attach all four extracted files to ChatGPT. You do not need to edit them.
3. Optional: attach lecture slides/PDFs or instructor material for better course alignment.
4. Send:

Create a compatible Emergency Medicine Case Pack using the attached objectives and reference materials. If lecture material is attached, use it for additional course alignment. Follow the AI Creator instructions exactly and give me one downloadable JSON file containing the cases.

5. Download the single JSON file ChatGPT creates and use Upload Finished Case Pack in the simulator.

Newly generated packs use a writing field matched to hidden, case-authored clinical keywords. One accepted keyword or phrase is enough to match an action. The mapped action and explanation appear after every submitted answer in Guided, Independent and Challenge. Existing packs without keyword response metadata keep their action-choice interface.

## Included

- EM_CASE_PACK_AI_CREATOR_v1.md — instructions with the schema and complete structural example embedded.
- EM_OFFICIAL_OBJECTIVES_v1.md — official course objectives with stable mapping IDs.
- EM_FIRST_AID_STUDY_CONTEXT_v1.md — designated reference citation and original study-alignment guide, NOT the textbook.
- This readme.

Lectures are optional. The official objectives are included permanently.
The full-course blueprint has 38 distinct topic groups (one duplicate source row is consolidated),
so full-course generation calls for 76 cases in one JSON, not three copies per learning level.
For a deliberately selected-topic pack, ask ChatGPT to state that narrower scope and audit all
objectives honestly. Do not accept a partial pack labelled as full-course coverage.
Large packs may require ChatGPT to work in stages, but the final deliverable remains one
complete JSON file. Do not truncate cases or drop objectives to fit a response.
